A single self-contained Python program that writes one roast line about a gadget used every day — the smart TV that demands a 40-minute software update to play a 22-minute episode — to /output/entry.txt. One line, 136 characters, standard library only, no network, byte-identical on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, one line, 136 characters).
